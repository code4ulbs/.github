# Code4ULBS

Code4ULBS este o echipă de voluntari — profesioniști și studenți — care dezvoltă soluții digitale pentru Universitatea „Lucian Blaga” din Sibiu. Prin colaborarea dintre [Sibiu IT Cluster](https://sibiu-it.ro/) și [ULBS](https://ulbsibiu.ro/), contribuim la digitalizarea educației și construim software cu impact local.

Inițiativa creează o punte între mediul tech și cel academic: studenții lucrează la proiecte reale alături de mentori și profesioniști, transformând nevoi concrete în aplicații moderne pentru comunitatea universitară.
